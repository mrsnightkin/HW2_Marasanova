# Калькулятор на Python
Программа выполняет вычисление математических выражений, задействующих базовые математические операции - **сложение/вычитание/умножение/деление**.
Программа принимает на вход выражение вида: `5 + 3` и выводит результат вычисления
## Особенности программы
- в качестве операторов деления распознаются символы `/`, `:`.
- в качестве операторов умножения распознаются символы `*`, `x`.
- деление на ноль невозможно
